# 미래 자산 계산기

월급과 소비·저축 계획을 바탕으로 일정 기간 뒤의 예상 자산을 계산하는 프로젝트입니다. 같은 주제를 각자 구현하고 결과물과 코드를 공유합니다.

## 프로젝트 정보

| 항목 | 내용 |
| --- | --- |
| **기간** | 2026-11-08 ~ 2026-11-16 (예정) |
| **결과 공유** | 2026-11-16 오후 9시 온라인 모임 (한국 시간) |
| **언어** | Python 사용, 버전은 각자 선택 |

## 프로젝트 방향

수입과 소비 습관, 저축이나 투자에 관한 가정을 바탕으로 미래 자산을 예상합니다. 기능과 요구사항은 각자 상황과 관심사에 맞게 자유롭게 정합니다.

아래는 구현할 수 있는 아이디어이며 필수 기능은 아닙니다.

- 월급과 소비 계획을 입력하고 월별 잔액 계산하기
- 예금·적금 납입액, 이율과 기간을 바탕으로 예상 자산 계산하기
- 투자 수익률을 가정하고 몇 년 뒤 자산 비교하기
- 계획을 저장하고 수정하거나 다양한 시나리오를 비교하기

계산 결과에는 기간과 수익률 등 적용한 가정을 함께 설명해 주세요. 세금이나 실제 상품 조건을 반영하지 않았다면 그 내용도 표시해 주세요.
