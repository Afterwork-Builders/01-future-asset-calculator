# 미래 자산 계산기

연봉과 월별 지출 계획을 입력해 일정 기간 동안 자산이 어떻게 변하는지 터미널에서 확인하는 프로그램입니다.

## 1차 마일스톤

우선 아래 기능을 중심으로 로컬 설정과 터미널 메뉴를 갖춘 간단한 프로그램의 틀을 개발합니다.

## 주요 기능

- **설정 조회·수정:** 시작 연월, 시작 자산, 연봉과 월별 생활비·고정비를 확인하고 수정합니다. 변경한 값은 로컬 설정 파일에 저장합니다.
- **미래 자산 조회:** 조회할 개월 수를 양의 정수로 입력하면 해당 시점의 예상 자산을 확인합니다.
- **목표 자산 달성 시점 조회:** 목표 금액을 입력하면 달성까지 걸리는 개월 수를 계산합니다.

메뉴에서 종료를 선택해 프로그램을 마칠 수 있습니다.

## 기술과 개발 환경

- **언어:** Python 3
- **실행 방식:** 터미널
- **설정 파일:** `config.json` (JSON 형식, 금액 단위: 원)
- **상태 저장:** 설정을 `config.json`에 저장합니다.
- **라이브러리:** Python 표준 라이브러리 (`curses`, `json`, `datetime`, `decimal`, `pathlib`)

## 설정 파일

`config.json`에 계산에 사용할 초기값과 매월 계획을 작성합니다. 설정값은 필요에 따라 수정합니다.

| 항목 | 의미 |
| --- | --- |
| `start_month` | 계산을 시작할 연월 (`YYYY-MM`) |
| `initial_cash` | 시작 시 보유한 현금 |
| `annual_salary` | 연봉 (12로 나눠 월급으로 사용) |
| `monthly_budget.living_expenses` | 월 생활비 |
| `monthly_budget.fixed_expenses` | 월 고정비 |

설정 파일은 계산에 필요한 초기값과 계획을 담으며, 계산할 개월 수는 조회할 때 입력합니다. 조회 결과는 저장하지 않고 현재 설정을 기준으로 매번 계산합니다.

## 실행 방법

`pileuszu` 폴더에서 `python3 main.py`를 실행합니다. 터미널에서 방향키와 Enter로 메뉴를 선택합니다. `curses`를 지원하는 터미널 환경이 필요합니다.

## 구현 내용

연봉을 12로 나눈 금액을 매월 수입으로 사용합니다. 매월 월급을 더하고 생활비와 고정비를 빼서 자산을 계산합니다. 시작 연월을 첫 계산 월로 삼아 입력한 개월 수만큼 계산합니다. 예를 들어 시작 연월이 2026-10이고 1개월을 조회하면 2026-10의 결과를 표시합니다. 자산이 부족하면 음수로 표시하고 경고합니다. 이자와 세금은 반영하지 않는 단순 예상치입니다. 목표 자산 달성 시점은 시작 자산과 월별 총자산 증가분을 기준으로 계산하며, 이미 달성했거나 현재 계획으로 도달할 수 없는 경우를 안내합니다.

### 파일 구성

- `main.py` — 설정을 불러오고 메인 메뉴를 실행합니다.
- `src/load_config.py`, `src/show_config.py`, `src/edit_settings.py` — 설정 파일 읽기, 표시와 수정
- `src/show_future_assets.py` — 미래 자산 계산과 결과 조회
- `src/show_goal_date.py` — 목표 자산 달성 시점 계산과 결과 조회
- `config.json` — 시작 연월, 자산과 월별 계획
