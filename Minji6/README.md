# 미래 자산 계산기

> 월급과 소비·저축 계획을 바탕으로 일정 기간 뒤의 예상 자산을 계산하는 프로젝트

## 주요 기능

- 월급, 저축, 투자, 소비 금액을 입력한다.
- 저축·투자·소비를 입력할 때마다 남은 잔액을 보여준다.
- 연 5%를 단순 월 이율로 환산해 이번 달 적금 이자를 계산한다.
- 투자 수익률은 적용하지 않고, 투자 원금만 보여준다.

## 실행 방법

Python 3.10 이상이 설치된 상태에서 아래 명령어를 실행합니다.

```bash
python main.py
```

## 계산 방식

```text
잔액 = 월급 - 저축 - 투자 - 소비
현재 적금 = 이번 달 저축액 + (이번 달 저축액 × 연 5% ÷ 12)
```

저축과 투자는 잔액에서는 빠지지만 내 자산 안에서 이동한 금액이므로, 총자산을 계산할 때 다시 더합니다.

## 가정과 한계

- 적금은 연 5%를 단순히 12개월로 나눠 한 달 이자를 계산합니다.
- 세금, 수수료, 우대금리, 실제 상품 조건은 반영하지 않습니다.
- 주식은 투자 원금만 보여 주며, 수익과 손실은 반영하지 않습니다.
